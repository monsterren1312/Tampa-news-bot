# Tampa News Telegram Bot

Автоматически публикует новости города Тампа (Флорида) на русском языке в
Telegram-канал **@TampaNews1**. Источники — RSS-ленты местных телеканалов
(FOX13, WFLA, 10 Tampa Bay, Bay News 9). Перевод и переписывание текста — через
Anthropic API (Claude). Публикация — через Telegram Bot API. Запускается по
расписанию через GitHub Actions, без сервера.

Это тот же бот-движок, что и для LA News — просто с другими источниками и
подписью в конце постов (`🌴 Tampa News` вместо `🇺🇸 LA News`).

## Что нужно сделать один раз перед запуском

### 1. Канал уже существует
Канал **@TampaNews1** уже создан, бот **@aipostbot** уже добавлен туда админом
с правом публикации (это было сделано раньше). Дополнительных действий с
самим каналом не требуется.

### 2. TELEGRAM_CHAT_ID
`@TampaNews1` (можно использовать username напрямую, канал публичный).

### 3. TELEGRAM_BOT_TOKEN
Тот же токен, что и для LA News-бота (тот же самый бот @aipostbot обслуживает
оба канала) — если он уже сохранён где-то с прошлой настройки, можно
использовать повторно. Если нет — @BotFather → `/mybots` → @aipostbot →
`API Token`.

### 4. ANTHROPIC_API_KEY
Тот же ключ, что уже используется для других ботов (или новый с
console.anthropic.com) — можно переиспользовать один и тот же ключ на
несколько репозиториев/каналов, лимиты общие на аккаунт.

### 5. CHANNEL_URL
`https://t.me/TampaNews1`

## Настройка репозитория на GitHub

Точно так же, как делали для LA News:

1. Создай новый **приватный** репозиторий (например `tampa-news-bot`).
2. Через **Add file → Create new file** создай файлы по одному, вписывая
   полный путь в поле имени (это надёжнее, чем загрузка zip/скрытых папок
   через drag-and-drop):
   - `bot.py`
   - `requirements.txt`
   - `state/seen.json`
   - `.github/workflows/post.yml`
3. Settings → Secrets and variables → Actions → New repository secret,
   добавь четыре секрета:

   | Имя секрета          | Значение                          |
   |-----------------------|------------------------------------|
   | `TELEGRAM_BOT_TOKEN`  | токен @aipostbot                  |
   | `TELEGRAM_CHAT_ID`    | `@TampaNews1`                     |
   | `ANTHROPIC_API_KEY`   | ключ с console.anthropic.com      |
   | `CHANNEL_URL`         | `https://t.me/TampaNews1`         |

4. Вкладка **Actions** → включить workflows, если попросит.

## Проверка первого запуска

1. Actions → **"Tampa News Autoposter"** → **Run workflow** (ручной запуск).
2. Посмотри логи — там будет видно, какие из 4 источников реально отдали
   новости, а какие вернули ошибку (RSS-адреса телеканалов иногда меняются —
   если какой-то из них не сработает, лучше сразу заменить в `bot.py`).
3. Проверь канал @TampaNews1 — должны появиться 1-2 новых поста на русском.

**Важно:** RSS-адрес Bay News 9 в `bot.py` помечен как "проверить при первом
запуске" — это наименее надёжный из четырёх, у некоторых локальных
телеканалов адрес RSS периодически меняется. Если он не сработает — не
страшно, остальные три источника продолжат работать, бот не упадёт целиком
(это встроено в логику `fetch_candidates`). Просто замени или убери его из
списка `RSS_SOURCES`, если увидишь ошибку в логах именно по нему.

## Добавление/замена источников

Открой `bot.py`, список `RSS_SOURCES` в начале файла. Формат:
```python
{"name": "Название для логов", "url": "https://адрес-rss-ленты"}
```
Просто добавь, убери или замени строку — при следующем запуске подхватится
автоматически.

## Всё остальное

Дедупликация, расписание (каждые 30 минут, максимум 2 поста за запуск),
обработка ошибок — устроены так же, как в LA News-боте. Подробности в
логике самого `bot.py` (комментарии на русском внутри файла).
